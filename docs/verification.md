| 构建产物密钥扫描 | 0 处泄漏 |

冒烟测试发现并修复两个问题：

1. Next.js 读取 `.env` 时会展开 `$`（加单引号也不例外），Argon2 哈希被截断，导致所有涉及登录的请求返回 500。改为在 `.env` 中写 `\$`，配置读取时还原；`hash-password` 直接输出转义后的整行。
2. 登录与退出的跳转原来用 `request.url` 拼绝对地址，在反向代理后会指向 `localhost`。改为相对地址。

未配置可信代理时，应用拿不到可信的客户端地址，所有登录尝试共用一个限流桶：伪造转发头无法绕过，但他人连续失败会让所有者也暂时无法登录。部署到 Nginx 后设置 `TRUST_PROXY=true`，由 Nginx 用 `$remote_addr` 覆盖 `X-Real-IP`。
